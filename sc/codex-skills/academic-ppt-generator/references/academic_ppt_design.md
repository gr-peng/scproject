# Academic PPT Design Reference

Use this reference when composing slide outlines or reviewing generated decks.

## Slide Density

- Use one primary message per slide.
- Prefer 3-5 bullets, each under 12 words.
- Split overloaded slides instead of shrinking text.
- Reserve dense tables for appendix or handout-style decks.

## Visual Grammar

- Use title as the slide's claim.
- Use left-to-right flow for methods and pipelines.
- Use before/after or baseline/proposed columns for comparisons.
- Use callout boxes only for the most important result or caveat.
- Use consistent color semantics: one color for proposed method, one for baseline, one for warning or limitation.

## Academic Storyline

Short research talk:

1. Hook: why the problem matters.
2. Gap: what prior work misses.
3. Idea: the core method or hypothesis.
4. Evidence: experiments, analysis, or proof.
5. Takeaway: what the audience should remember.

Paper summary:

1. Problem and motivation.
2. Contributions.
3. Method.
4. Evaluation.
5. Results and limitations.
6. Discussion questions.

## Editable Element Policy

Use editable PowerPoint objects by default. Raster images are acceptable only for source figures, photos, screenshots, heatmaps, or charts that cannot be recreated faithfully. Add editable labels or captions around raster figures.
